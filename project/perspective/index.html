Perspective

Perspective is a Python diary-backup library, also called psp. It grew out of preserving entries from the iOS journaling app Perspective, with the broader aim of keeping diaries usable outside the application that created them. It is an independent project, not the app’s official library.

Keep the dates, the words, and the attachments

The library represents dated collections of entries as panels. Its JSON loader and dumper handle text and references to external files, while the formatter produces readable, line-wrapped diary text. Time-zone handling lets entries retain their original offsets or be displayed in a common time zone.

Source and documentation

Clone the repository with: git clone https://git.rapidcow.org/pub/project/perspective.git

The Perspective documentation includes the published 0.1 series, its API reference, and examples. The Python package is under src/ in the repository; its import namespace is psp.
