liblist

liblist implements rapid’s property list: a small, line-oriented key–value format inspired by mail and HTTP headers. A space separates a key from its value, and indentation continues a value over multiple lines. It is unrelated to Apple’s property list formats.

Implementations

The repository contains a Python implementation in rdks_list/ and a Perl implementation in PairList/. The Python rdks.list reader and writer retain formatting information alongside key–value pairs; they also support byte strings without imposing a text encoding.

One use of the format is the configuration language for libmail’s compose.py. The libraries provide the reader and writer; the application gives the keys their meaning.
