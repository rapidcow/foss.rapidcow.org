libmail

libmail is a collection of mail utilities. Its Python package, rdks.mail, includes MIME transfer encoders and decoders, Message-ID parsing, Outlook Thread-Index utilities, and integrations with Python’s email package.

Describe the message you want to make

With compose.py, a message’s MIME structure becomes a text document you can edit and reuse. Describe a multipart message, load its plain-text and HTML parts from files, and choose charsets, transfer encodings, attachment names, and headers in the same input. The composer turns that description into calls to Python’s email library and libmail’s encoders.

compose.py

compose.py constructs MIME messages from a text-based configuration language. It uses the library’s mail components and rdks.list. Template Toolkit can generate that input as a separate preprocessing step.

Documentation and source layout

The Python documentation is not published here yet. The repository contains Sphinx sources under docs/src/, including the compose language reference in docs/src/compose.rst. The implementation is under rdks/mail/ and its tests are under tests/.

The repository also contains a separate Java implementation of quoted-printable utilities under java/, with a Gradle build and tests. It is separate from the Python package.
