siteconf

siteconf is like autoconf and automake but for generating web sites. siteconf is written in Perl and adapted from numerous experiments from cooper-www, www-cellar, and (more recently) javadoc.rapidcow.org. its canonical (git clone) URL is git+https://git.rapidcow.org/pub/project/siteconf.git. Packages are not built but I will tag the git releases (and maybe a change log when I find convenient)

As of now, the latest version of WwW-SiteConf is 0.0300 (tagged siteconf/v0.03_00 (we renamed!)), the latest version of WwW-GenLib is 0.0300 (tagged genlib/v0.03_00), and the latest version of WwW-GenGenLib is 0.0100 (tagged gengenlib/v0.01_00).

As of siteconf 0.03, the minimum Perl version has been increased to 5.008, and non-UTF-8 locales are supported. The siteconf-l10n source tree contains gettext translation for Simplified Chinese (which is at present, vastly LLM-generated).

Mirrors on GitHub, GitLab, BitBucket, Gitee and GitCode.

Note that unlike most of my Perl code, siteconf is in fact more copyleft than usual (GPL version 3 or later).
