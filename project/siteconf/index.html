siteconf

siteconf is like autoconf and automake but for generating web sites. siteconf is written in Perl and adapted from numerous experiments from cooper-www, www-cellar, and (more recently) javadoc.rapidcow.org. its canonical (git clone) URL is git+https://git.rapidcow.org/pub/project/siteconf.git. Packages are not built but I will tag the git releases (and maybe a change log when I find convenient)

As of now, the latest version of WwW-SiteConf is 0.0202 (tagged engine/v0.02_02 or v0.02_02), the latest version of WwW-GenLib is 0.0202 (tagged genlib/v0.02_02), and the latest version of WwW-GenGenLib is 0.0002 (tagged gengenlib/v0.00_02).

The only Gitweb mirror is on GitHub. Maybe I will mirror it in a different place when I respect myself and this code more, but with the sheer volume it stands it can only be considered vibe coded and subpar for hosting even on Gitwebs that do not have a strong stance against AI like Codeberg and SourceHut.

Note that unlike most of my Perl code, siteconf is in fact more copyleft than usual (GPL version 3 or later).
