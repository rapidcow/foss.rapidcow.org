List::Search

This is an information page regarding the "List-Search" distribution I have adopted from Edmund von der Burg (EVDB).

Source code (Git repository)

Since the author told me that he lost the SVN repository, the code now canonically exists on Codeberg (with history imported from BackPAN):

https://codeberg.org/rapidcow/p5-List-Search

Mirrors exist:

  • https://git.rapidcow.org/pub/lib/perl5/List-Search.git
  • GitHub: https://github.com/rapidcow/p5-List-Search
  • SourceHut: https://git.sr.ht/~rapidcow/p5-List-Search (a little bit outdated from an earlier import; don't use just yet!)

Tags will be signed by my perl@rapidcow.org key. I have also uploaded the key to Codeberg and GitHub, so you can verify from the green badge without fetching the keys yourself.

If you happen to have stumbled upon my repository at this time, though, please pardon my force updates on tags and default branch while I haven't uploaded to CPAN! I really want to make it right even for the original versions.

Report bugs
