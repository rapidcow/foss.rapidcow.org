Perspective (stub)

This is a stub page for Project Perspective, an attempt to migrate my diary entries from the iOS app Perspective, and — in the process of achieving so — specify a neutral format for bodies of text tagged by date and time.

The Perspective library (also known as the psp library, out of fear of getting called out for plagiarizing the name), written in Python, provided an interface for:

  • psp.types: Entry/Panel object model (a Panel being a container consisting of entries written on or about a specific day)
  • psp.processors.json: Parser that converts between JSON and the object model.
  • psp.stringify: presentation of the object model as line-wrapped, formatted text.

The Perspective library was, at one point, open source at <https://github.com/rapidcow/perspective>. It is open source in spirit, but I had removed all (known) copies from the Internet, due to its (simultaneous) code-like and journal-like nature. It makes me uncomfortable publishing it since I consider it to be an important part of me; and the thought of badly programmed security bots forking it brought discomfort. (It may not offend me as much now, but I felt pretty betrayed that the first PR I received was not even a real person, and I’m apparently responsible for hunting down this unknown researcher group now who might not even care about me. (I know I had invoked the nasty "my repository had no explicit GPL license text" thing but I wholeheartedly want to make open source software :c I only did that because (1) I felt like the code was subpar, being my first Python library ever, and (2) I don’t like it when literal bots interact with my code before humans do." I actually don’t have such problems, now that I have abandoned using Internet domain emails, so if anyone clones it they are just further legitimizing my decentralized, non-revocable domain names, so… that’ll help greatly! >:D))
