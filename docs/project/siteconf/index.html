siteconf

siteconf is like autoconf and automake but for generating web sites. siteconf is written in Perl and adapted from numerous experiments from cooper-www, www-cellar, and (more recently) javadoc.rapidcow.org. its canonical (git clone) URL is git+https://git.rapidcow.org/pub/project/siteconf.git. Packages are not built but I will tag the git releases (and maybe a change log when I find convenient)

As of now, the latest version of WwW-SiteConf is 0.00_00 (tagged engine/v0.00_00) and the latest version of WwW-GenLib is 0.00_00 (tagged genlib/v0.00_00).
